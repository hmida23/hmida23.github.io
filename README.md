# Personal Portfolio Website

A clean, high-performance personal portfolio built from scratch using pure HTML5 and modern CSS3. Designed with a focus on minimal overhead, fast load times, and responsive layouts across all device sizes.

🔗 **Live Demo:** [https://<username>.github.io/<repository-name>/](https://<username>.github.io/<repository-name>/)

---

## ⚡ Performance & Philosophy

As a computer science student passionate about systems efficiency and low-level performance, I deliberately avoided heavy front-end frameworks (like React or Bootstrap) for this static site.

- **Zero External Dependencies:** Pure Vanilla HTML & CSS.
- **Fast Load Time:** Minimal assets, zero runtime overhead.
- **Responsive Layout:** Built with CSS Flexbox & Grid for smooth scaling across mobile, tablet, and desktop viewports.
